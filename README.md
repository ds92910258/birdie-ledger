# 버디장부 · 무료 운영용 수정본

Lovable AI 크레딧 없이 직접 개발하는 정적 React 앱입니다. 이름·휴대폰·비밀번호로 가입 신청하고 총무가 승인합니다. Supabase Auth/DB와 서버 권한 검사를 사용합니다.

## 현재 검증 상태
- Vite 프로덕션 빌드, TypeScript 검사, 단위 테스트 9건 통과.
- 실제 Supabase 무료 프로젝트 연결 완료.
- 문자 없는 가입 신청/로그인/승인 대기, 승인 전 데이터 차단, 일반 회원의 관리자 API·역할 쓰기 차단을 실제 API로 검증.
- 트랜잭션 테스트로 승인 후 점수 등록, +23타 벌칙금 2만원, 납부/잔액 반영 확인. 테스트 데이터는 모두 정리.
- 웹 화면의 최종 배포/브라우저 검증은 배포 후 필요.

## 최초 총무 설정
- 제공받은 일회용 총무 설정 코드로 앱의 `/#/setup` 화면에 접속해 본인 비밀번호를 직접 설정합니다.
- 아이디는 `admin`입니다. 최초 설정이 끝나면 설정 페이지가 잠깁니다.
- 설정 코드는 소스에 저장하지 않으며 DB에는 해시만 저장됩니다. 분실하면 프로젝트 소유자만 DB에서 재발급할 수 있습니다.
- Supabase 서비스 역할 키는 Edge Function 내부에서만 사용합니다. 프런트엔드에는 공개 publishable key만 있습니다.

## 연결된 서버 기능
- `member-signup`: 이름·전화번호·비밀번호를 검증해 가입 신청을 생성. SMS/이메일 발송 없음. 전화번호 소유를 인증한 것은 아니므로 총무가 실제 회원인지 확인합니다.
- 번호당 시간당 3회, 전체 시간당 50회 가입 시도로 제한합니다.
- `admin-setup`: 비공개 설정 코드로만 총무 생성. 일반 가입·이름으로 관리자 권한을 얻을 수 없습니다.
- 서버의 역할 테이블과 회원 상태를 기준으로 모든 장부 접근과 변경을 검증합니다.
- 신규 환경 재생성 시 초기 스키마와 후속 migration을 적용하고 Edge Function을 배포해야 합니다. 기존 연결 DB에 초기 스키마를 다시 적용하지 마세요.

## GitHub Pages 배포
- GitHub Free에서 Pages는 공개 저장소 사용 조건입니다. 소스 코드는 공개되지만 회원·회비 데이터는 Supabase에서 RLS로 보호합니다. 실제 개인정보나 비밀키를 저장소에 넣지 않습니다.
- 공개 소스에 동의하지 않으면 Cloudflare Pages 등 다른 무료 정적 호스팅을 선택할 수 있습니다.
- 저장소 Variables에 VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY 등록 후 Settings → Pages → GitHub Actions 선택. 동봉 워크플로가 타입 검사/테스트/빌드를 실행합니다.
- 해시 라우팅을 사용해 하위 디렉터리에서도 새로고침이 동작합니다.

## 사용
회원: 휴대폰 번호로 로그인, 본인 점수 입력/수정(납부 전), 개인 그래프와 공동 장부 조회.
총무: 게임 생성, 회원 승인/거절/해제, 모든 점수 관리, 납부 처리, 입출금 취소와 변경기록 확인.
벌칙금: +9 이하 0원, +10~19 1만원, +20~29 2만원, 이후 10타마다 1만원.
회비 잔액은 실제 납부와 기타 수입에서 지출을 차감하며 미납을 더하지 않습니다.

## 남은 제한
- SMS 인증·셀프 비밀번호 재설정 없음. 비밀번호를 잊으면 프로젝트 소유자가 Supabase에서 재설정해야 합니다.
- 백업은 내보내기만 제공합니다. 가져오기는 금융 내역 중복 방지 검증 후 추가할 예정입니다.
- 무료 요금제의 데이터/트래픽/휴면 제한은 제공사 정책에 따릅니다. 유료 플랜 전환이나 결제는 자동 진행하지 않습니다.
