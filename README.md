# 버디장부 · 무료 운영용 수정본

Lovable AI 크레딧 없이 직접 개발하는 정적 React 앱입니다. 이름·휴대폰·비밀번호로 가입 신청하고 총무가 승인합니다. Supabase Auth/DB와 서버 권한 검사를 사용합니다.

## 현재 검증 상태
- Vite 프로덕션 빌드 성공
- TypeScript 검사 통과
- 벌칙금·잔액·전화번호·통계 단위 테스트 9건 통과
- 실제 Supabase 프로젝트 미연결. 실가입/승인/RLS/관리자 설정의 실제 환경 검증은 아직 안 됨. 운영 준비 완료로 간주하지 마세요.

## 운영 전 연결
1. 본인 소유 Supabase 무료 프로젝트 생성. 기존 Lovable 데이터베이스와 별개입니다.
2. SQL 편집기에서 `drizzle/migrations/0000_migration.sql` 적용. 새 프로젝트에 한 번만 실행합니다.
3. Auth에서 이메일/비밀번호 가입 활성화, 이메일 확인 비활성화. 휴대폰 번호를 내부 인증 식별자로 변환하며, 일반 회원에게 이메일/SMS를 보내지 않습니다. 문자인증을 했다는 의미가 아닙니다. 총무가 실제 회원인지 확인해야 합니다.
4. `.env.example`의 두 공개 설정을 실제 프로젝트 URL/공개 publishable key로 채워 빌드합니다. 서비스 역할 키와 관리자 설정 토큰은 프런트엔드나 Git에 넣지 않습니다.
5. `supabase/functions/admin-setup/index.ts`를 Supabase Edge Function `admin-setup`으로 배포합니다. 이 함수의 JWT 검사는 꺼져 있으며, 관리자 생성은 서버 비밀 토큰으로 보호됩니다.
6. Supabase 함수 Secrets에 본인이 직접 만든 충분히 무작위인 32자 이상 `ADMIN_SETUP_TOKEN` 등록. 토큰을 채팅에 보내지 마세요. `APP_ORIGIN`은 실제 사이트 origin으로 설정합니다.
7. 앱의 `/#/setup`에서 토큰과 새 비밀번호(10~72자)를 직접 입력. 성공 후 `admin`으로 로그인합니다. 관리자 존재 이후 설정이 잠깁니다. 토큰은 삭제할 수 있습니다.
8. 테스트 회원 가입 → pending 확인 → 총무 승인 → 공동 장부/점수 입력 확인. 승인 전 다른 데이터 접근 차단과 회원의 관리자 API 호출 차단을 검증한 뒤 회원에게 공유하세요.

## GitHub Pages 배포
- GitHub Free에서 Pages는 공개 저장소 사용 조건입니다. 소스 코드는 공개되지만 회원·회비 데이터는 Supabase에서 RLS로 보호합니다. 실제 개인정보나 비밀키를 저장소에 넣지 않습니다.
- 공개 소스에 동의하지 않으면 Cloudflare Pages 등 다른 무료 정적 호스팅을 선택할 수 있습니다.
- 저장소 Variables에 VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY 등록 후 Settings → Pages → GitHub Actions 선택. 동봉 워크플로가 타입 검사/테스트/빌드를 실행합니다.
- 해시 라우팅을 사용해 하위 디렉터리에서도 새로고침이 동작합니다.

## 사용
회원: 휴대폰 번호로 로그인, 본인 점수 입력/수정(납부 전), 개인 그래프와 공동 장부 조회.
총무: 게임 생성, 회원 승인/거절/해제, 모든 점수 관리, 납부 처리, 입출금 취소와 변경기록 확인.
벌칙금: +9 이하 0원, +10~19 1만원, +20~29 2만원, 이후 10타마다 1만원.
회비 잔액은 실제 납부와 기타 수입에서 지출을 차감하며 미납을 더하지 않습니다.

## 남은 제한
- SMS 인증·셀프 비밀번호 재설정 없음. 비밀번호를 잊으면 프로젝트 소유자가 Supabase에서 재설정해야 합니다.
- 백업은 내보내기만 제공합니다. 가져오기는 금융 내역 중복 방지 검증 후 추가할 예정입니다.
- 무료 요금제의 데이터/트래픽/휴면 제한은 제공사 정책에 따릅니다. 유료 플랜 전환이나 결제는 자동 진행하지 않습니다.
